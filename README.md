# Chess Club Tournament & Rating Manager

Term project · Introduction to Database Management Systems · THGA Bochum
Author: Yahya El Idrissi · Due: 13.09.2026

Self-hosted system for running Swiss-system chess tournaments: records game
results, maintains Elo ratings over time, and answers performance questions
across a player's whole game history.

**Stack:** PostgreSQL 16 · FastAPI · tkinter · Docker Compose
